## 怎样开始

### 想领养
1. 浏览宠物档案
2. 点击「立即领养」
3. 填写申请表
4. 等待审核
5. 面谈并接宠物回家

### 想捐献
1. 点击「我要捐助」
2. 选择金额
3. 填写信息
4. 完成捐献
5. 收到感谢信和成果报告

### 想做志愿者
1. 点击「加入志愿者」
2. 告诉我们你的技能
3. 等待联系
4. 参加简单培训
5. 开始改变

### 想分享
1. 点击「分享我们」
2. 选择社交媒体
3. 分享故事
4. 帮助宠物被看见
